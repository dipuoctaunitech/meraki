# Boutique Frontend

Next.js App Router storefront for the boutique ecommerce site.

## Pages

- `/` — Landing page
- `/dresses` — Product listing
- `/dresses/[id]` — Product detail with size selection
- `/cart` — Shopping cart

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment

Optional backend URL if you add API integration later:

```bash
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000/api/v1
```
